Ferramentas modulares da WA WEB Design para os sites de seus clientes.

== Description ==

O WA Suit organiza funcionalidades independentes em módulos. A estrutura
inicial inclui SEO, WooCommerce, diagnósticos e conversão, prontos para receber
implementações específicas.

== Installation ==

1. Envie a pasta `Plugin-WA-Suit` para `/wp-content/plugins/`.
2. Ative o WA Suit no menu **Plugins** do WordPress.
3. Acesse **WA Suit** no painel administrativo para habilitar ou desabilitar
   módulos.

== Requirements ==

* WordPress 6.0 or later
* PHP 7.4 or later

== Uninstallation ==

As configurações e os dados são preservados ao desinstalar o plugin.
